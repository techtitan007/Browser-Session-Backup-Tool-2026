## 🛠️ Troubleshooting

### The tool does not detect my browser

Make sure the browser is installed in the default location. If you installed it to a custom folder, go to Settings and manually point the tool to the browser's executable file.

### Restore is not working

Close all windows of the browser you are trying to restore. Then try the restore again. The tool needs to open the browser fresh to restore the session.

### The tool will not open

Right-click the tool and select "Run as Administrator." Some Windows settings require admin rights for programs to work properly.

### Backups are not saving

Check that you have write permission to the backup folder. The default folder is "Documents\Browser Session Backups." You can change this in Settings.

### Windows SmartScreen warning appears

This is normal. Click "More Info" and then "Run Anyway." The tool is safe, but SmartScreen sometimes flags new programs.
